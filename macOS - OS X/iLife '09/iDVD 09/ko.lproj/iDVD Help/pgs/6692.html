하드 디스크의 프로젝트 파일 이동 또는 이름 변경하기

프로젝트를 여는 동안 iDVD 프로젝트에서 사용한 파일(예를 들어, 동영상, 슬라이드쇼 또는 노래)의 이름을 변경하거나 이동했다면, 프로젝트는 변경사항을 반영하도록 업데이트되지 않습니다. 결과적으로 프로젝트를 디스크에 구우면 이동되거나 이름 변경된 파일이 포함되지 않습니다. 하지만, 프로젝트 소스 파일을 이동하거나 이름 변경하기 전에 iDVD 프로젝트를 닫으면, 프로젝트를 다시 열 때 iDVD에서 해당 파일을 다시 찾아줍니다.

제거하거나 이름을 변경한 프로젝트를 찾으려면,

프로젝트를 여십시오.

경고 대화상자가 한 개 이상의 항목이 유실되었음을 표시하고 유실된 항목을 찾을 것을 요청합니다.

파일 찾기를 클릭하고 유실된 파일을 선택하십시오.

유실된 다른 파일이 동일한 위치에 있다면, iDVD에서 이들 파일을 찾고 다시 연결해 줍니다.

프로젝트에서 없어진 파일을 제거하려면, 메뉴, 슬라이드쇼 또는 동영상 단추에서 해당 파일에 대한 참조를 삭제하고 프로젝트를 저장하십시오.
