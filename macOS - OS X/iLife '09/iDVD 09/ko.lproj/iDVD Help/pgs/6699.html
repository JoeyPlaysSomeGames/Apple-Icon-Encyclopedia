드롭존에서 동영상의 실행 시간 설정하기

드롭존에 동영상을 추가할 때 재생 시간을 지정할 수 있습니다. 예를 들어, 드롭존에 4분 분량의 동영상을 추가할 때 실행 시간을 변경하여 30초 동안만 재생되도록 할 수 있습니다.

하나의 DVD 메뉴에는 동영상을 추가하는 몇 개의 드롭존, 이미지 단추 및 동영상을 추가하는 메뉴 배경이 있을 수 있습니다. 동일한 메뉴에 대한 모든 이런 동영상은 동일한 실행 시간을 가지고 있습니다. 따라서, 하나의 실행 시간을 변경하면 모든 실행 시간이 변경됩니다. 설정할 수 있는 최대 실행 시간은 메뉴 상의 최장 동영상 길이입니다. 최대 15분까지 지원됩니다.

드롭존 동영상의 실행 시간을 변경하려면,

수정하려는 드롭존이 포함된 메뉴가 iDVD 윈도우에 나타나는지 확인하십시오.

포인터를 메뉴 위에 둔 상태로 Command-I를 눌러 메뉴 정보 윈도우를 여십시오.

루프 실행 시간 슬라이더는 선택한 메뉴(드롭존에 또는 메뉴 배경으로서)에 추가된 최장 시간의 동영상 길이를 나타냅니다.

루프 실행 시간 슬라이더를 드롭존 동영상을 재생시키려는 시간(초)으로 드래그하십시오. 이 메뉴에 포함된 최장 동영상 길이까지 지원됩니다.

메뉴에 여러 동영상이 있으며 루프 실행 시간을 최대(동영상 내에서 최장 동영상의 실행 시간)로 설정했다면 더 짧은 동영상이 가장 긴 동영상이 재생될 때까지 루프됩니다.
