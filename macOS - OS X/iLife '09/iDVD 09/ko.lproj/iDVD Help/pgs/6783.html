메뉴 안의 단추에 아무 링크도 없습니다

iDVD 메뉴에 동영상, 슬라이드쇼 또는 이미지 폴더를 드래그하면, 추가하는 컨텐츠에 대해 해당 파일 또는 폴더의 이름을 가진 단추가 자동으로 생성됩니다. 이 단추는 클릭하면 올바른 컨텐츠로 링크됩니다. 하지만, iDVD 윈도우에서 추가 단추(아래 참조)를 사용하여 슬라이드쇼 또는 동영상을 추가할 때는 위치 지정 단추만 해당 메뉴에 추가됩니다. 이 단추는 컨텐츠를 드래그할 때까지 아무 곳에도 링크되지 않습니다.

단추를 컨텐츠에 링크시키려면,

미디어 패널 또는 하드 디스크나 연결된 서버 아무 곳에서나 동영상, 슬라이드쇼 또는 이미지 폴더를 DVD 메뉴에서 생성한 단추로 드래그하십시오.

더하기 기호가 있는 녹색 원이 보이면 파일을 드롭하십시오.

iDVD는 올바르지 않은 종류의 파일은 단추에 드롭되는 것을 허용하지 않습니다. 예를 들어, 슬라이드쇼를 동영상에 대해 생성된 단추로 드래그할 수 없습니다.

동영상 단추를 추가했으나 여기에 아직 동영상을 링크하지 않았다면, 메뉴에 노란색 경고 아이콘이 있는 단추가 나타납니다. 이 경고 아이콘은 맵 보기에서도 나타납니다. 슬라이드쇼가 링크되어 있지 않은 슬라이드쇼 단추를 추가하면 맵 보기에 빨간색 경고 아이콘이 나타나서 슬라이드쇼가 비어 있음을 표시합니다.
