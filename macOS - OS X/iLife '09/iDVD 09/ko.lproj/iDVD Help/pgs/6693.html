파일을 디스크의 DVD-ROM 부분에 추가하기

파일을 디스크의 DVD-ROM 부분으로 추가하는 방법으로 DVD 사용자가 디스크에서 직접 파일을 복사하도록 할 수 있습니다. 이들 파일은 DVD에 구워지며 해당 디스크를 Windows PC 또는 Macintosh 컴퓨터(DVD 플레이어가 아닌)에서 볼 때 접근할 수 있게 됩니다.

이 디스크에는 모든 유형의 파일을 추가할 수 있습니다. 예를 들어, 디스크에 슬라이드쇼가 포함되어 있다면 이미지 파일을 디스크의 DVD-ROM 부분에 추가하여 시청자들이 이들을 자신의 컴퓨터에 다운로드하고 프린트할 수 있게 할 수 있습니다. 또한 동영상 제작 노트 및 기타 항목이 포함되어 있는 파일을 추가할 수도 있습니다.

파일을 디스크의 DVD-ROM 부분에 수동으로 추가하려면,

고급 > DVD-ROM 컨텐츠 편집을 선택하십시오.

DVD-ROM 컨텐츠 윈도우가 열립니다.

파일 추가를 클릭하거나 파일을 넣을 폴더를 생성하려면 새로운 폴더를 먼저 클릭하십시오.

탐색하여 파일 또는 폴더를 선택한 다음, 열기를 클릭하여 이들을 디스크에 추가하십시오.

또한, 파일을 DVD-ROM 컨텐츠 윈도우에 직접 드래그할 수 있습니다. 완료하면 윈도우를 닫기만 하면 됩니다.

파일을 디스크의 DVD-ROM 부분에 추가할 때 디스크를 굽기 전에는 프로젝트에는 실제 파일이 아닌 하드 디스크상에서 파일의 위치에 대한 참조만 포함되어 있습니다. 따라서, DVD-ROM 컨텐츠에 파일을 추가한 다음, 파일을 컴퓨터에서 삭제하거나 현재 위치에서 다른 곳으로 이동하면, 디스크를 구울 때 "파일을 발견할 수 없습니다"라는 오류 메시지가 나타납니다. 유실된 이들 파일을 DVD-ROM 컨텐츠에서 제거하거나 컴퓨터상에서 찾아서 원래 위치로 복귀하여 iDVD에서 접근하게 할 수 있습니다.

DVD-ROM 컨텐츠에 파일을 추가할 때 프로젝트 정보 윈도우의 DVD 용량 측정기에서 얼마나 많은 기가바이트의 디스크 공간이 사용되고 있는지 확인하십시오. 용량 측정기는 DVD-ROM 부분뿐 아니라 디스크의 비디오 부분이 차지하는 디스크 공간을 표시합니다.

참고: 이 기능을 사용하여 DVD에 일반 시스템 백업을 생성하지 않는 것이 좋습니다. 컴퓨터의 하드 디스크에 DVD 백업 파일을 만들려면 Finder에서 디스크 굽기 기능을 사용하십시오.
